Protección de Datos

Política de Privacidad Transparente

1. Principio Local-First

Nexora App no requiere creación de cuenta de usuario ni recopila correos electrónicos. Tu lista de activos guardados (Watchlist) y preferencias de interfaz se guardan únicamente en la base de datos local de tu teléfono mediante Room (SQLite).

2. Peticiones de Red Directas y Cifradas

Las consultas de precios de mercado e inteligencia artificial se conectan de forma directa y cifrada (HTTPS/TLS 1.3) a Twelve Data API, ExchangeRate API y Google Gemini AI API. Ningún dato de identificación personal es transmitido.

3. Permisos Mínimos del Sistema

La aplicación solicita únicamente el permiso android.permission.INTERNET para descargar las cotizaciones de mercado en tiempo real. No accedemos a contactos, archivos, ubicación ni cámara.
